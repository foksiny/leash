Standard Library Reference

Leash ships with a set of standard libraries in the installthis/ directory. These libraries provide common utilities like type aliases for explicit bit-width types, math functions, string manipulation, tuple containers, JSON, UTF-8, hex, Base64, UUID generation, and a windowing API. Install them globally to make them available from any project via the use statement.

The standard libraries are optional — you can install only the ones you need, or write your own libraries following the same patterns.

Installation

# Install all standard libraries globally
leash install installthis/

# Then import in any project
use types::*;
use math::Math;
use str::Str;

Library Imports

Basic Import Syntax

use module_name::ItemName;
use hash::Hash;
use colors::Color;

// Import all public items
use mylib::*;

Private Imports

// Import without re-exporting
priv use mylib::*;

pub fnc helper() : int {
    return lib_priv();  // can use private items
}

Nested Paths

use math::operations::add;
use utils::string_helpers::capitalize;

The compiler searches for modules in two locations:

  1. The local directory of the file containing the use statement (including subdirectories)
  2. The global libraries directory (~/.leash/libs/) — where installed libraries are available from anywhere

When you import a module, all its public definitions (structs, classes, enums, functions, templates, etc.) become available in your file. This makes it easy to organize code into reusable, namespaced modules.

Tuple Library (tuple.lsh)

A generic Tuple<T> class for storing a collection of values. Tuples provide a lightweight way to group items without defining a custom struct, with methods for indexed access, membership testing, and size queries.

MethodDescription
Tuple.new(vals T[])Create a new Tuple from an array
.get(idx int)Get the element at index idx
.isin(val T)Check if a value exists
.sizeNumber of elements (property)
use tuple::Tuple;

fnc main() {
    t: Tuple<int> = Tuple.new({1, 2, 3});
    show(t.get(1));   // 2
    show(t.isin(3));  // true
}

JSON Library (json.lsh)

A full JSON parser, serializer, and pretty-printer built entirely in Leash. It supports objects, arrays, strings (including \uXXXX escapes and surrogate pairs), integers, floats with exponents, booleans, and null. Errors are reported through an ok / err pair instead of crashing, so malformed input is easy to handle gracefully.

use json::*;

fnc main() {
    let v: JsonValue = Json.parse("{\"name\": \"Leash\", \"year\": 2026}");
    if v.ok == false {
        show("parse error: " + v.err);
        return;
    }
    show(v.get("name").as_string());  // Leash
    show(v.get("year").as_int());     // 2026
    show(Json.pretty(v));              // pretty-printed
}

JSON Types

JsonType is an enum with the values JNULL, JBOOL, JINT, JFLOAT, JSTRING, JARRAY, and JOBJECT.

The JsonValue Class

A JsonValue wraps a single JSON value. It carries a typ field plus a slot for each kind of data, and an ok / err pair for reporting parse or access failures.

Building Values from Scratch

Construct JsonValues with struct initialization and compose them with set / push_back:

obj: JsonValue = JsonValue { typ: JsonType::JOBJECT, ok: true };
obj.set("msg", JsonValue { typ: JsonType::JSTRING, sval: "built", ok: true });
obj.set("count", JsonValue { typ: JsonType::JINT, ival: 7, ok: true });
show(Json.stringify(obj));  // {"msg":"built","count":7}

UTF Library (utils/utf.lsh)

UTF-8 encoding and decoding utilities. Encoding accepts any code point and produces the canonical UTF-8 byte sequence; decoding validates the input and reports failures through a UtfDecoded struct instead of crashing. Surrogates and out-of-range code points are rejected, and overlong / malformed byte sequences are never accepted.

use utils::utf::*;

fnc main() {
    show(Utf.encode(0x1F600));               // 😀
    show(Utf.length("Aé😀"));               // 3 (code points)
    show(Utf.valid("Aé"));                  // true
    cps: vec<int<64>> = Utf.codepoints("Aé");
    show(Utf.from_codepoints(cps));          // "Aé"
}

The UtfDecoded Struct

.okboolWas the byte at i a valid sequence start?
.cpint<64>The decoded code point (0 when ok is false)
.lenintNumber of bytes consumed (1–4)

Hex Library (utils/hex.lsh)

Hexadecimal conversion utilities: digit mapping, string ↔ bytes, and string ↔ integer conversions. All parsing is case-insensitive and strict — invalid input yields an empty result or -1 instead of crashing.

use utils::hex::Hex;

fnc main() {
    show(Hex.from_int(255));               // "ff"
    show(Hex.to_int("0xDEADBEEF"));         // 3735928559
    show(Hex.from_int_pad(255, 8));         // "000000ff"
    bytes: vec<char> = Hex.to_bytes("deadbeef");
}

Base64 Library (utils/base64.lsh)

Standard Base64 encoding and decoding (RFC 4648 alphabet). Decoding skips whitespace, enforces canonical padding, and rejects non-alphabet characters, leftover bits, and misplaced = signs — invalid input decodes to an empty result.

use utils::base64::Base64;

fnc main() {
    show(Base64.encode("foobar"));          // Zm9vYmFy
    show(Base64.decode("Zm9vYmFy"));          // foobar
    bytes: vec<char> = Base64.decode_bytes("Zg==");  // raw bytes of "f"
}

The Base64 Class (Statics)

Base64.decode_bytes(s)vec<char> of decoded bytes; empty on invalid input
Base64.decode(s)Decoded string; "" on invalid input

UUID Library (utils/uuid.lsh)

UUID generation and validation. Uuid.v4() produces a random RFC 4122 version-4 UUID using the standard library rand builtin; parsing and validation are strict.

use utils::uuid::Uuid;

fnc main() {
    id: string = Uuid.v4();
    show(id);                                    // e.g. 8cd4bd3f-e5ce-429f-9733-f5f981e92e66
    if Uuid.valid(id) == false { return; }
    raw: vec<char> = Uuid.bytes(id);              // 16 raw bytes
}

Hot Reloader (hotreload.lsh)

The Reloader watches a Leash source file for changes and automatically re-runs it. This is particularly useful during development when you want a live-reload workflow — edit your code and see the results immediately without manually re-running the compiler.

use hotreload::Reloader;

fnc main() {
    r: Reloader = Reloader.new("main.lsh");
    r.start();
}

Window Library (utils::window)

The low-level lshraylib binding is unstable and buggy. The utils::window library is the new, in-development replacement that wraps raylib in a Leash-native API.
use utils::window::*;

wind: LshWindow;
pos: Vector2;
speed: int = 5;

fnc start() {
    pos = Vector2 { x: wind.width / 2, y: wind.height / 2 };
}

fnc update() {
    sizes := Vector2 { x: 50, y: 50 };
    Draw.draw_rect(pos, sizes, WHITE);

    if Input.key_down(KEY_W) { pos.y -= speed; }
    also Input.key_down(KEY_S) { pos.y += speed; }
    also Input.key_down(KEY_A) { pos.x -= speed; }
    also Input.key_down(KEY_D) { pos.x += speed; }
}

fnc main {
    wind = create_window(800, 600, "My Game");
    close_key(KEY_ESCAPE);
    init_window(wind, &start, &update, &endd);
}
