Leash

What is Leash?

Leash combines an intuitive syntax with native performance, targeting developers who want the control of a systems language without the ceremony. It compiles directly to machine code via LLVM, ships with a package manager and a 100+ package standard library, and supports cross-platform development from a single source tree.

Leash was made with the help of AI, but its design and ideas come from a human. The AI’s role was to implement the language and toolchain and to write the documentation. The human and the AI also stress-tested Leash — checking where it fails and where it wins, then fixing quirks as they were found. Bugs are addressed right away, which is why all features (and 90%+ of them in practice) are kept stable and reliable.

Version 2.0.0 made the scoped bump arena the default native memory layout. It gives you plain C pointers, deterministic frame and loop lifetimes, and no stop-the-world pause. If your workload has adversarial or highly dynamic lifetimes, pass --gc to opt into the classic mark-and-sweep collector.

Why Leash?

Leash is built for people who want a small, predictable language that still offers modern conveniences. There is no virtual machine to install on native targets, no Python build step, and no external debugger to configure. The shipped compiler is itself written in Leash, so the language is continuously dogfooded by its own toolchain.

Good to know. A default leash compile produces a standalone native binary. The arena runtime is compiled and linked for you; you do not need to install LLVM development libraries or a garbage collector to get started.

Feature tour

Breadth is only useful if it all works together. These are the capabilities you get out of the box in 2.0.0.

Strongly Typed

Full type inference with explicit bit-width integers, floats, generics, and tagged unions.

Restricted Literal Types

def status : type "ok", "error", nil; accepts only listed literals. Invalid values and widening to the base type are compile-time errors.

LLVM-Powered

Compiles to native code via LLVM with multiple optimization levels including LTO and PGO.

Self-Hosted Compiler

Since 1.0 the shipped leash compiler is written in Leash: installation bootstraps it (a checked-in seed binary builds stage 1, stage 1 builds itself) and verifies the bootstrap fixed point — 89/89 example programs match the reference compiler byte-for-byte (the corpus was recorded from the original reference compiler; entries added after it was retired come from the current self-hosted compiler).

Zero-Cost Abstractions

Classes, generics, lambdas, and operator overloading compile down to efficient machine code.

Built-in GC & Arena

A scoped bump arena is the default native layout, with deterministic frame/loop reclamation, poison-on-reclaim safety, C-ABI-friendly pointers, recursive graph escapes, and a compile-time lifetime audit. Opt into --gc mark-and-sweep, or choose nogc and --autofree for GC-free binaries.

Package Manager

leash pkg (built into the compiler) publishes, installs and manages libraries with semantic versioning and per-project reproducible builds via leash.lock.

Cross-Platform

Compile for Linux (x64/ARM64), Windows, and macOS from a single source with conditional compilation.

Native Web Stack

http ships a full HTTP/HTTPS client with HTTP/2 (h2c + h2 over TLS); httpserver adds a multiplexed keep-alive server speaking HTTP/1.1 and HTTP/2, plus a TLS listener — both dependency-free.

Native Debugger

leash dbg steps or breakpoints any program without GDB/LLDB — source-level stops, set from the CLI or interactively.

Concurrency

Worker threads, shared/fusion variables, and native async/await with future<T>.

Shared Variables

A function can declare program-wide storage in its signature (fnc f() : void | result: int); only the functions that declare it may touch it, and every one of them sees the same storage. Distinct from the shared/fusion worker globals, which are module-wide and carry the thread-safety rules.

Rich Standard Library

100+ importable packages: vectors, hash maps, graphs, files, math, HTTP/SQL, compression, parsing, testing helpers, and more.

Quick start

From a fresh checkout to a running native binary in four steps.

Install the toolchain

Clone the repository and let the Python-free bootstrap script build the self-hosted compiler.

# Build the self-hosted compiler (Python-free)
git clone https://github.com/foksiny/leash && cd leash
./scripts/bootstrap.sh
bin/leashc version
# leash 2.4.4 (self-hosted)

Write a program

Put this in a file called hello.lsh. The main function is the entry point; show prints to standard output.

fnc main() : void {
    show("Hello, World!");
}

Run it directly

No output binary is created in this mode — handy while iterating.

# Run directly — the compiler is written in Leash itself
leash run hello.lsh

Compile to native code

Build a standalone executable and run it like any other program.

# Compile to native binary
leash compile hello.lsh to hello
./hello
# Hello, World!
Success. That binary uses the default scoped arena. To swap in the mark-and-sweep collector, add --gc to the compile command: leash compile hello.lsh to hello --gc.

Core concepts

A few ideas recur throughout the language and the rest of this documentation.

Values and types

Variables can be explicitly typed or inferred with :=. Integers come in explicit bit widths, and the checker catches mistakes before you link a binary.

fnc main() : void {
    count: int = 42;
    label := "items";
    show(label, ": ", tostring(count));
}

Collections and iteration

Generic containers such as vec<T> are part of the core language, and foreach walks them with both index and value.

fnc main() : void {
    nums: vec<int>;
    nums.extend({3, 1, 4, 1, 5});
    foreach i, n in<vector> nums {
        show("[", i, "]: ", n);
    }
}

Memory and lifetimes

In the default arena, a pointer stays valid until the frame or loop iteration that allocated it exits. Values that must outlive their frame are copied into the caller or the program-lifetime root arena. There is no borrow checker and no GC pause, but that means raw pointers and manual heap calls are audited strictly; see memory management modes.

Design trade-off. If your data has cycles, escapes through raw pointers, or otherwise has hard-to-express lifetimes, compile with --gc. The arena is fast and deterministic but intentionally compile-or-fail on unsafe lifetime patterns.

Modules and projects

Single files are fine for experiments. For larger programs, leash init scaffolds a project with a config.lshc, an imports/ directory, and an out/ directory. use module::Item; pulls in standard and installed packages.

Ecosystem

Leash is more than a compiler. The standard library covers collections, math, text, networking, SQL, compression, encoding, and testing; the built-in package manager handles versioned dependencies with a reproducible leash.lock; and the native HTTP/HTTPS client and server make networked programs dependency-free. Concurrency is available through workers, shared/fusion globals, and async/await with future<T>.

Compiler pipeline

Leash transforms source code into a native executable through a multi-stage pipeline. Each stage feeds its output into the next, from raw source text all the way to a linked binary. The pipeline includes lexical analysis, parsing, type checking, optimization at both the AST and LLVM IR levels, code generation, and final linking with the selected memory runtime. The compiler reference documents all fifteen stages.

.lsh source
  ├─ Lexer (characters → tokens)
  ├─ Parser (tokens → AST)
  ├─ Import Resolution
  ├─ Conditional Compilation
  ├─ Macro Expansion
  ├─ Type Checker
  ├─ Low-Level Checker
  ├─ AST Optimization
  ├─ Code Generation (AST → LLVM IR)
  ├─ Alloca Hoisting
  ├─ Re-parse & Verify
  ├─ LLVM Optimization
  ├─ Object Emission
  ├─ C Runtime Compilation
  └─ Linking → Native Binary

FAQ

Is the arena safe without a borrow checker?

Yes for all programs the compiler accepts. The arena roots values that outlive a frame, tracks raw-pointer provenance through locals, publishes root blocks to workers, and rejects the few patterns it cannot prove safe with E_ARENA_LIFETIME. Poison-on-reclaim, frame verification and escape snapshots are on by default, so a missed root copy aborts instead of silently dangling. See the lifetime audit.

Is Leash garbage collected?

Not by default in 2.0.0. Native builds use the scoped bump arena unless you pass --gc. You can also build fully GC-free binaries with --no-garbage-collector (manual free()) or --autofree (automatic release at function exit).

Do I need Python or LLVM development libraries?

No. The compiler ships as a native binary and the bootstrap script is Python-free. You only need a C compiler for linking; LLVM development headers are not part of the setup.

Is the compiler really written in Leash?

Yes. Installation builds the checked-in seed, the seed compiles the sources into stage 1, and stage 1 compiles itself to verify the fixed point. See Self-Hosted Compiler.

Which platforms can I target?

Linux (x64 and ARM64), Windows, and macOS natively, plus a JVM bytecode target that runs anywhere Java runs. See compilation targets.
