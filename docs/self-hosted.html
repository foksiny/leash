Self-Hosted Compiler

Since the 1.0 release, the compiler you install as leash is written in Leash itself. The sources live in compiler/*.lsh: tokens.lsh, ast.lsh, lexer.lsh, parser.lsh, typechecker.lsh, optimize.lsh, codegen.lsh, driver.lsh, and main.lsh. It emits LLVM IR text and links against the same Leash runtime/GC (leash/gc.c) through clang.

The self-hosted compiler is a 1:1 replica of the Python reference compiler on the whole example corpus — 88/88 programs compile and run with identical output — and it implements the entire toolchain natively: compile, run (file and project modes), check, dump, init, build, install, update, self-host, and the interactive dbg debugger. The Python implementation remains available as leashp (for cross-compilation targets other than linux64, and as the reference for parity testing).

Bootstrap Pipeline

StageAction
Stage 0Python compiler builds compiler/main.lsh into bin/leashc_stage1
Stage 1leashc_stage1 compiles compiler/main.lsh into bin/leashc_stage2
Stage 2leashc_stage2 compiles compiler/main.lsh into bin/leashc_stage3
Fixed pointStage 2 IR and Stage 3 IR must be textually identical (modulo comments/whitespace)

How to Build

bash scripts/bootstrap.sh
# or
leash self-host

Installing the package already bootstraps the compiler (stage 0 + one self-compilation). From a repository checkout, leash self-host runs the full pipeline natively — Stage 0–2, a fixed-point check that diffs the stage 2 and stage 3 IR, and installs bin/leashc as the official self-hosted compiler.

Using the Self-Hosted Compiler

leash compile examples/hello.lsh -o /tmp/hello
/tmp/hello

# run directly (temp binary, "Executed at" banner, exit code propagation)
leash run examples/hello.lsh

# emit LLVM IR only
leash compile file.lsh --emit-llvm -o file

# rebuild itself from source
leash self-host

Tests live in tests/test_self_hosted.py (python3 -m unittest tests.test_self_hosted).

Parity and Verification

The self-hosted frontend covers the full language: primitives, pointers, references, arrays, slices, vec, matrix, hash, structs, classes (instance + static methods and fields, vtables, inheritance), enums, unions, generics (class, def T : template, multi-type [int, float, ...] parameters with monomorphization), opdef operator overloading, error/throw, big integers (int/uint up to 512 bits), async/await futures, the File API, lambdas, tuples, macros, and the string-interpolated show family (including buffered showb).

  • scripts/ir_diff.py — the parity harness: runs every example under both compilers and compares outputs (88/88 exact match, 0 mismatches, 0 compile failures)
  • scripts/bootstrap.sh / leash self-host — the 3-stage bootstrap with a hard fixed-point check
  • tests/test_self_hosted.py — the compiler test suite (python3 -m unittest tests.test_self_hosted)
